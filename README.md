# Myldre

A tilted 3D night map of Norway where public transport vehicles move live on real terrain. Buses, ferries and trains show up as small low-poly models, using positions from the [Entur Vehicle Positions API](https://developer.entur.no/docs/open-services/vehicle-positions).

This is a side project for fun, and a place to try SolidJS, MapLibre, deck.gl and later Rust.

Status: planning. See [PLAN.md](PLAN.md) for milestones and [GLOSSARY.md](GLOSSARY.md) for terms.

## Data

Vehicle positions come from Entur under the [Norwegian Licence for Open Government Data (NLOD)](https://data.norge.no/nlod/en/2.0). Map data comes from [OpenFreeMap](https://openfreemap.org) and OpenStreetMap contributors.
